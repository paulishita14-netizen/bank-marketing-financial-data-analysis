# Bank Marketing Financial Data Analysis

## Week 1 Internship Project – Understanding Financial Data

This project analyzes the **Bank Marketing Dataset** from the UCI Machine Learning Repository. The dataset contains information about customers contacted during direct marketing campaigns of a Portuguese banking institution.

The objective of this project is to understand customer characteristics, perform data cleaning, conduct exploratory data analysis (EDA), and identify patterns associated with term-deposit subscription.

## Dataset

**Dataset:** Bank Marketing Dataset  
**Source:** UCI Machine Learning Repository

Dataset link:  
https://archive.ics.uci.edu/dataset/222/bank%2Bmarketing

The dataset contains **45,211 customer records** and information related to customer demographics, financial status, previous campaign interactions, and the outcome of the current marketing campaign.

### Target Variable

- `y = yes` → Customer subscribed to a term deposit
- `y = no` → Customer did not subscribe to a term deposit

## Key Outcome

The analysis shows that term-deposit subscription rates vary across different customer and campaign characteristics. The project demonstrates how financial data can be cleaned, explored, summarized, and visualized to identify useful patterns in customer behavior.

The observed relationships represent associations in the dataset and should not be interpreted as proof of causation.
